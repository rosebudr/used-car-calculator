# 🚗 스마트카 중고차 감가상각 & 법정 취등록세 계산기

대한민국 행정안전부 고시 자동차 시가표준액 산정 잔가율과 지방세법, 지자체 조례에 따른 정확한 중고차 실거래 시세 및 법정 취등록세·부대비용 종합 산출 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **3단계 계층형 차량 선택 (대분류 > 중분류 > 소분류)**:
   - 17개 국산/수입 주요 브랜드 (현대, 기아, 제네시스, BMW, 벤츠 등)
   - 대표 차종 및 세부 세대 모델별(예: 그랜저 HG 2011~2016년) 공식 출시 기간 및 평균 신차 출고가 매핑
2. **신뢰성 높은 시세 3단 산출**:
   - **내 차 팔 때 (도매 / 딜러 매입가)**: 상사 마진 및 상품화 비용 공제 견적
   - **추천 개인 직거래**: 매매 수수료 없는 최적 실거래가
   - **내 차 살 때 (소매 시세)**: 엔카/KB차차차/K-Car 등록 소비자 최종 구매 기준가
3. **법정 세무 & 부대비용 정밀 명세**:
   - **행정안전부 법정 시가표준액**: 지방세법 제10조의2 과세기준 하한선 실시간 산출
   - **취득세**: 승용 7%, 경차 4% (최대 75만원 전액 감면), 하이브리드 최대 40만원 감면, 전기차 최대 140만원 감면
   - **공채 채권**: 1,600cc 미만 비영업용 승용차 100% 면제(0원) 및 배기량별 실부담 할인액
   - **기타 법정 부대비용**: 매매상사 매도비(관리비용 38만원), 성능점검 책임보험료(부품별 4~25만원), 등록 인지/증지대
4. **구글 애드센스 규정 100% 준수**:
   - 개인정보처리방침 (Google DoubleClick DART 쿠키 명시)
   - 이용약관 및 서비스 소개
   - 반응형 광고 슬롯 (헤더, 본문 상/중/하단, 모달 배너)
   - 웹 표준 구조화 데이터 (`schema.org` WebApplication, FAQPage)

## 🚀 배포 및 자동 업데이트 (Git Push & Auto-Deploy)

이 저장소는 GitHub 및 **Vercel** / **GitHub Pages**에 연동되어 있습니다.

로컬에서 코드를 수정하고 터미널에서 커밋/푸시하면 **30초 내에 배포 사이트에 자동 반영**됩니다:

```bash
# 1. 파일 수정 후 변경사항 스테이징
git add .

# 2. 커밋 메시지 작성
git commit -m "feat: 새로운 차종 데이터 추가"

# 3. 원격 저장소로 푸시 (자동 배포 트리거)
git push origin main
```

## 💰 구글 애드센스 (Google AdSense) 승인 가이드

1. **애드센스 가입 및 사이트 등록**:
   - [Google AdSense](https://www.google.com/adsense) 접속 후 회원가입 / 로그인
   - [사이트] 메뉴에서 본인의 도메인 등록
2. **코드 삽입**:
   - 발급받은 본인의 게시자 ID(`ca-pub-XXXXXXXXXXXXXXXX`)를 `index.html`과 `ads.txt`에 교체 입력
3. **개인 도메인 연결**:
   - Vercel의 [Settings] > [Domains]에서 구매한 도메인(예: `mycar-calc.com`) 입력
   - DNS 레코드(A 레코드 또는 CNAME)를 설정하면 무료 SSL(HTTPS) 인증서가 자동 발급됩니다.
